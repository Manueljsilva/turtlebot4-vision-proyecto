# Compartir el proyecto con el grupo

Repositorio: [Manueljsilva/turtlebot4-vision-proyecto](https://github.com/Manueljsilva/turtlebot4-vision-proyecto), privado (verificado el 6 de noviembre de 2026).

El repositorio contiene código, notebooks sin salidas, pruebas e instrucciones.
Las fotos de alumnos, galería facial, resultados personales, capturas, modelos
descargados y `.venv` permanecen locales. Cada integrante debe obtener el dataset
por el canal del curso y preparar los modelos siguiendo el README de cada tarea.

Para preparar una copia nueva desde la raíz del proyecto:

```bash
python3 preparar_github.py
```

El comando indica una carpeta en `/tmp` con los archivos publicables. Respeta
`.gitignore` y limpia las salidas únicamente en las copias de los notebooks.
Los originales y sus ejecuciones se conservan. Esta exportación prepara los
archivos: no hace una subida ni configura credenciales de GitHub.

Antes de cada nueva subida, generar la copia limpia; no subir directamente los
notebooks ejecutados. En un repositorio privado, los compañeros necesitan acceso
como colaboradores; conocer el enlace por sí solo no da acceso. Nunca compartir
contraseñas o tokens por el chat ni guardarlos en los archivos del proyecto.

Una vez publicado y aceptada la invitación, los compañeros pueden descargarlo:

```bash
git clone https://github.com/Manueljsilva/turtlebot4-vision-proyecto.git
```

El clon contiene el código y las instrucciones, sin los datos locales excluidos.
